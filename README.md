Every point holds its territory. Give one more weight and it pushes the borders; relax them all and the cells settle into a honeycomb.

## What it does

- **Weighted cells:** a heavier point takes more space
- **Lloyd relaxation** moves points to the centroids until the cells even out
- **Boundary:** rectangle, square, circle or hexagon; roundness turns cells into mercury drops
- **Presets** from 6 to 16 sites, a spring morph between states
- **Export:** PNG, SVG and a JSON config

## Run it

Open [robvagin.github.io/voronoi](https://robvagin.github.io/voronoi/), or download `index.html` and open it from your disk. It is the whole tool: no build step, no dependencies, no network. Press **H** to hide the panel.
